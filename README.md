# Sven Withus

KI- und E-Commerce-Integrator aus NRW · [sven-withus.com](https://sven-withus.com)

Ich entwickle und betreibe E-Commerce-Systeme seit 2008 und baue heute LLMs in diese Systeme ein.
Meine Arbeitsweise ist AI-native: Ich plane, zerlege und prüfe, Agenten schreiben den Großteil des Codes,
Hooks und Tests erzwingen die Regeln.

## Woran ich arbeite

- **Agenten-Setup für Claude Code und Codex:** Orchestrator plus Fach-Agenten für Code-Review, Security-Audit,
  Deployment und adversariale Prüfung, Hooks gegen gefährliche Befehle und Schreibzugriffe auf Live-Pfade,
  Secret-Scan vor jedem Commit, Gates mit Testsuiten und Mutationsproben. Ein bereinigter Auszug ist öffentlich:
  [claude-code-guardrails](https://github.com/withus/claude-code-guardrails).
- **LLMs in eigenen Werkzeugen:** Claude in Gmail als Chrome-Erweiterung, eine mehrstufige SEO-Artikel-Pipeline
  mit Qualitätsschranken, ein Claude-Plugin für die eigene Buchhaltung.
- **Shops:** Neubau eines Produktkonfigurators von CodeIgniter 3 auf CodeIgniter 4 (PHP 8.3, Shield,
  Stripe Payment Intents), headless Verlagsshop mit React, TypeScript, Supabase (RLS, Edge Functions), Stripe
  und Storyblok.
